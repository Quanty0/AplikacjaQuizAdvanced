# AplikacjaQuizAdvanced
Nasza aplikacja quizowa będzie bardzo zaawansowana.
Praca będzie podzielona na wiele etapów, gdzie każda osoba z grupy będzie miała przydzielone zadanie do wykonania.
Aplikacja będzie głównie zbudowana za pomocą AI, próbując nowe chaty i modele.
Projekt współtworzony przez Quanty0, Strobenn, Shatore22 oraz BartekR308.
